# Ассеты «Карамель»

Сайт подхватывает файлы из этой папки сам. Пока их нет, работает CSS-карамель и 3D-объекты, отрисованные в браузере.

Формат тот же, что был у плюша: PNG/WebP, белый или прозрачный фон, анфас для плашек и кнопок. Имена можно не соблюдать: файлы разложит Claude.

- obj-study / obj-time / obj-info / obj-money / obj-bots / obj-space — объекты групп
- word-hero — слово «ПОРЯДОК»
- plate-lime / sky / pink / orange / lilac / sun / lavender / violet — плашки карточек (9-slice)
- btn-sun / btn-violet / btn-white — кнопки-таблетки (9-slice)

Плюшевая версия сайта сохранена в ветке `style-plush`.
